# morph027/homebrew-tap

Homebrew formulae by morph027.

```bash
brew install morph027/tap/aws-ssm-juggle
```

Or tap first, then install by name:

```bash
brew tap morph027/tap
brew install aws-ssm-juggle
```

| --- | --- |
| `aws-ssm-juggle` | [morph027/aws-ssm-juggle](https://github.com/morph027/aws-ssm-juggle) |

Formulae are bumped automatically from PyPI by GitHub Actions (`.github/workflows/`).
